1. Маркетплейс: продуктовые метрики и A/B-тест

Диагностика выручки, когортная экономика привлечения и оценка бонуса на первую покупку.

Методы: SQL · Python · продуктовые метрики · A/B.

Результат: В эксперименте с 2 968 участниками разница конверсии составила +6,44 п.п.; подготовлены рекомендации по привлечению и удержанию.

Стоимость бонусов отсутствует в данных, поэтому чистый финансовый эффект не рассчитан. Участники имеют разные окна наблюдения.

2. Procrastinate Pro+: окупаемость привлечения

Анализ активности, удержания и окупаемости рекламных каналов.

Методы: Python · когорты · CAC/LTV/ROI.

Результат: Средний ROI 25 зрелых недельных когорт FaceBoom: −48,36%. Разделены рекомендации по каналам и срокам оценки.

Молодые когорты имеют неполный период наблюдения. Сроки окупаемости зависят от горизонта анализа.

3. Доставка: воронка и сегментация клиентов

Поиск потерь в пользовательском пути, сегментация покупателей и партнёров.

Методы: Python · воронки · RFM · K-Means.

Результат: Разрыв конверсии подтверждения телефона между мобильной и десктопной версиями: около 35,5 п.п. Подготовлены гипотезы для проверки.

Причины потерь в воронке и эффективность предложенных механик требуют отдельной проверки.

4. SollmaFin: A/B-тест онбординга

Проверка качества эксперимента и изменений депозитов после добавления обучения.

Методы: Python · A/B · SRM · бутстрап.

Результат: На 9 415 участниках выявлен дисбаланс групп: SRM p = 0,004. Рекомендована проверка распределения и повторный эксперимент.

Из-за SRM выводы об эффекте предварительные; статистически значимый рост основной метрики не установлен.
