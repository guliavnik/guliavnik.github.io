Просмотр и запуск

Откройте index.html: в каждом проекте есть готовые результаты для просмотра в браузере. Для тетрадок доступны HTML с графиками и исходный .ipynb; для SQL — итоговые запросы и описание задач.

Код при подготовке этой подборки повторно не выполнялся. HTML показывает сохранённые результаты. Изменены оформление, служебные комментарии и две итоговые формулировки, согласованные с сохранёнными значениями.

Для выполнения Python установите зависимости из requirements.txt и откройте тетрадку в JupyterLab. CSV не включены в подборку: адреса и имена файлов находятся в коде. Сохранённые наборы данных лежат в полной выгрузке, в папке «Финальные проекты спринтов/Данные». Локальные пути в исходном коде могут потребовать настройки под ваше окружение.

SQL написан для PostgreSQL. Для выполнения нужна соответствующая схема базы данных. Данные сервера SQL не входят в подборку; исходные запросы прошли проверку платформы.
