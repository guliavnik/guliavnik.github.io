# Procrastinate Pro+: окупаемость привлечения

**Задача:** Анализ активности, удержания и окупаемости рекламных каналов.

**Методы:** Python · когорты · CAC/LTV/ROI.

**Результат:** Средний ROI 25 зрелых недельных когорт FaceBoom: −48,36%. Разделены рекомендации по каналам и срокам оценки.
