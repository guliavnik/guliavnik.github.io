# Маркетплейс: продуктовые метрики и A/B-тест

**Задача:** Диагностика выручки, когортная экономика привлечения и оценка бонуса на первую покупку.

**Методы:** SQL · Python · продуктовые метрики · A/B.

**Результат:** В эксперименте с 2 968 участниками разница конверсии составила +6,44 п.п.; подготовлены рекомендации по привлечению и удержанию.
