# Мобильная игра: диагностика продуктовых метрик

**Задача:** Поиск причин снижения выручки при росте пользовательской базы.

**Методы:** SQL · MAU · удержание · воронка · монетизация.

**Результат:** Сопоставлены динамика удержания, прохождения уровней и покупок; сформулированы гипотезы о причинах изменений.
