# Телеком: тарифы и расходы клиентов

**Задача:** Расчёт ежемесячных расходов с учётом включённых услуг и превышения лимитов.

**Методы:** SQL · CTE · JOIN · расчёт тарифов.

**Результат:** Три итоговых расчёта: расходы по месяцам, средние расходы по тарифам и переплаты активных клиентов.
