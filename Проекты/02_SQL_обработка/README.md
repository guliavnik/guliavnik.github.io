# Телеком: тарифные начисления и переплаты клиентов

**Учебный проект · PostgreSQL · CTE · LEFT JOIN · UNION · CASE · месячные расчётные витрины.**

## Бизнес-задача

Рассчитать ежемесячные начисления клиентам с учётом абонентской платы и превышения лимитов услуг. Сравнить средние траты по тарифам и выделить активных клиентов с переплатой сверх абонентской платы.

## Что сделано и проверено

- Данные звонков, интернет-сессий и сообщений агрегированы до единого уровня **клиент × месяц** с помощью DATE_TRUNC и GROUP BY.
- Через UNION сформирован список клиентов и месяцев с активностью хотя бы в одном виде услуг. Источники соединены по составному ключу **user_id + месяц**, затем добавлены данные пользователей и справочник тарифов.
- Для минут, интернет-трафика и сообщений через CASE выделено потребление сверх включённых лимитов. Итоговое начисление рассчитано как абонентская плата плюс стоимость превышения по каждому виду услуг.
- В отдельных запросах отобраны действующие клиенты, рассчитаны их средние месячные траты и переплата сверх абонентской платы; денежные итоговые показатели округлены до двух знаков.

## Результат

Подготовлены **три SQL-расчёта**: начисления по каждому клиенту и месяцу, средние траты и число клиентов по тарифам, средняя переплата клиентов с превышением абонентской платы. Код показывает, как привести несколько источников к одной детализации и получить расчётную таблицу с прозрачной формулой начислений.

## Ограничения

Рассчитываются траты клиентов на услуги связи, а не расходы компании. Это учебная модель тарифных начислений, а не промышленная биллинговая система. Базой служат месяцы с зафиксированной активностью; клиенты без такой активности не образуют отдельные строки расчёта.

Данные PostgreSQL и выгрузки итоговых значений в подборку не входят. Поэтому здесь представлен код расчётов без неподтверждённых денежных итогов или заявлений о снижении расходов.

## EN summary

Prepared three PostgreSQL calculations for monthly customer charges, average spending by tariff and spending above the fixed monthly fee. Aggregated calls, internet usage and messages to a common customer-month grain before joining tariff data. This educational project calculates customer charges, not company operating expenses.
