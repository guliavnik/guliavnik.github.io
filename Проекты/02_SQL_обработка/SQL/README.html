1. Траты клиентов по месяцам

Файл с итоговыми запросами

Траты клиентов по месяцам

Решите первую задачу от коллег. Выгрузите данные о клиентах с информацией о потребляемых услугах за каждый месяц активности и посчитайте их месячные траты на действующем тарифном плане.

Для решения задачи посчитайте и выведите в новом обобщённом табличном выражении users_costs следующие данные:

  • user_id — идентификатор клиента;
  • dt_month — месяц статистики;
  • tariff — название тарифного плана клиента;
  • month_duration — суммарная длительность всех разговоров клиента в этом месяце;
  • month_mb_traffic — суммарное количество потраченных мегабайтов интернет-трафика в этом месяце;
  • month_sms — общее количество отправленных клиентом сообщений в этом месяце;
  • rub_monthly_fee — абонентская плата по тарифному плану;
  • total_cost — сумма общих трат клиента в этом месяце: сюда входят абонентская плата и платы за активность сверх тарифного плана — минуты разговоров, гигабайты и сообщения, которые не вошли в лимит.

При решении используйте результат обобщённого табличного выражения user_over_limits, а также данные по тарифам из таблицы tariffs. Для проверки расчётов в основном запросе выведите первые десять строк CTE users_costs, предварительно отсортировав выдачу по возрастанию значений user_id и dt_month.

2. Средние траты активных клиентов

Файл с итоговыми запросами

Средние траты активных клиентов

Следующая задача — рассчитать средние траты в месяц для активных клиентов, которые продолжают пользоваться услугами компании, в разрезе тарифного плана.

Чтобы решить эту задачу, для каждого тарифного плана рассчитайте уникальное количество клиентов и средние траты по тарифу. Для этого используйте результат обобщённого табличного выражения users_costs. Среднее значение трат по каждому тарифу округлите до двух знаков после точки.

Задачу решите в основном запросе с такими полями:

  • tariff — название тарифного плана клиента;
  • total_users — количество клиентов;
  • avg_total_cost — значение средних ежемесячных трат клиентов по тарифу.

3. Активные клиенты и их траты

Файл с итоговыми запросами

Активные клиенты и их траты

Последняя задача — для каждого тарифного плана посчитайте уникальных активных клиентов, чьи ежемесячные траты превышают абонентскую плату по тарифу. Выведите также их средние траты в месяц и среднее значение переплаты.

Задачу решите в основном запросе с такими полями:

  • tariff — название тарифного плана клиента;
  • total_users — количество клиентов;
  • avg_total_cost — средние ежемесячные траты клиента по тарифу;
  • overcost — средняя переплата клиента относительно ежемесячного платежа.

Полученные значения округлите до двух знаков после точки.
